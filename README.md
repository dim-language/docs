# DIM documentation

Documentation and examples for Diagram In Markup in Bahasa Indonesia and English.

```sh
bun install --frozen-lockfile
bun run dev
bun run check
bun run test
bun run build
```

Use Bun 1.4.3 and Node.js 24. The site uses a pinned release of the [TypeScript SDK](https://github.com/dim-language/dim-sdk) to compile the example models and render the maps. The [shop example](examples/shop/main.dim) and the [language specification](src/content/docs/en/referensi/spesifikasi.md) are maintained here.
