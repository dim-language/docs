Senin pagi, Dido dapat tiket untuk mendokumentasikan checkout toko online. Di tiket cuma ada satu kalimat dari tim produk. “Pembeli bisa pesan lewat toko.” Besok tim Web dan API akan membawa rancangan mereka. Hari ini Dido perlu menyiapkan peta yang bisa mereka koreksi bersama.

## Siapkan folder kerja

Simpan peta Dido di satu file `shop.dim`. Siapkan Node.js 24 dan Bun, lalu jalankan perintah berikut di terminal.

```sh
mkdir dim-checkout
cd dim-checkout
bun add https://github.com/dim-language/dim-sdk/releases/download/v0.3.1/dim-sdk-0.3.1.tgz
```

Simpan kode berikut sebagai `check.mjs` di folder itu. Skrip ini membaca file yang kamu berikan beserta `dim.config` di folder yang sama, menjalankan compiler, lalu mencetak jumlah elemen dan relasinya.

```js contoh-tutorial="check.mjs"
```

Simpan juga `dim.config` di folder yang sama. Di file ini Dido mendeklarasikan teknologi yang akan dipakai tim, sekali untuk seluruh proyek.

```dim contoh-tutorial="dim.config"
```

## Orang dan sistem

Buat file `shop.dim` dan isi dengan model berikut.

```dim contoh-tutorial="sistem.dim"
```

Setiap file diawali `dim "0.6";`. Setiap elemen punya jenis (`person` atau `system`), ID camelCase yang dipakai dalam path, dan nama yang tampil di peta. Relasi `shopping` punya id dan `op use`, dan panahnya menunjukkan bahwa pembeli yang memulai interaksi. Setiap statement tanpa blok diakhiri `;`.

```bash
node check.mjs shop.dim
```

```text contoh-tutorial="sistem"
```

Dua elemen dan satu relasi sudah cukup untuk menggambarkan siapa yang memakai toko online.
