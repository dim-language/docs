title: Panduan penggunaan
description: Pilih panduan berdasarkan perubahan yang ingin kamu buat.
---

Pilih pekerjaan yang sedang kamu hadapi. Kalau belum punya file `.dim`, mulai dengan [model pertama](/id/mulai/).

- [Petakan sistem yang sudah berjalan](/id/menulis/memodelkan/) — Mulai dengan satu pengguna, satu tindakan, dan layanan yang merespons.
- [Siapkan dim.config](/id/menulis/konfigurasi/) — Deklarasikan teknologi, tag, dan tampilan sekali untuk seluruh proyek.
- [Pilih elemen dan properti](/id/menulis/elemen/) — Tentukan batas sistem, peran container, dan paradigmanya.
- [Hubungkan dua elemen](/id/menulis/relasi/) — Beri id, pilih `op`, dan tulis path sumber dan tujuan.
- [Bedakan pemanggil dari arah data](/id/konsep/aliran-data/) — Catat request dan respons pada satu panah.
- [Dokumentasikan endpoint](/id/konsep/endpoint/) — Tulis kontrak HTTP, gRPC, GraphQL, atau event, lalu biarkan pemanggil memakainya.
- [Catat kontrak fungsi](/id/konsep/level-kode/) — Tuliskan tipe, parameter, hasil, dan error mengikuti paradigma kodenya.
- [Telusuri satu flow](/id/konsep/alur/) — Ikuti checkout dari klik sampai pesanan tersimpan, termasuk jalur gagalnya.
- [Pecah model menjadi beberapa file](/id/konsep/komposisi/) — Pisahkan bagian milik dua tim dan buat model *to-be*.
- [Petakan tempat software berjalan](/id/konsep/deployment/) — Tempatkan container ke cluster dan region per environment.
- [Baca panah saat zoom berubah](/id/konsep/peta-zoom/) — Temukan fungsi yang menulis ke database.
- [Pasang peta di halaman Astro](/id/ekosistem/peta-web/) — Bagikan model interaktif ke reviewer.
