Di proyek Astro, [pasang SDK](/id/referensi/cli/#pasang). Salin file akhir `shop.dim` beserta `dim.config`-nya dari [tutorial](/id/mulai/) ke `src/models/`. Simpan komponen berikut di `src/components/`.

```astro title="src/components/ShopMap.astro" contoh-tutorial="ShopMap.astro"
```

Buat halaman yang membaca model dan config-nya sebagai teks. Komponen mengompilasinya saat halaman dirender.

```astro title="src/pages/checkout.astro"
---
import ShopMap from '../components/ShopMap.astro';
import source from '../models/shop.dim?raw';
import config from '../models/dim.config?raw';
---
<ShopMap source={source} config={config} language="id" />
```

Jalankan dev server Astro dan buka `/checkout/`. Perbesar petanya sampai Web dan API terlihat. Pilih relasi POST untuk memeriksa request dan respons, seperti pada contoh yang dirender di sini.

<ShopMap source={source} config={config} language="id" />
