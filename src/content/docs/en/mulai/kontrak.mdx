In `toko.dim`, add a type for the order number to the Pesanan component, then change only the `pull` part of the POST relation. Web still sends a full order and the API still persists it.

```diff
+      alias idPesanan "IdPesanan" {
+        description "Nomor pesanan yang tampil di layar konfirmasi.";
+        type uuid;
+      }
```

```diff
-  data pull toko.api.pesanan.dataPesanan;
+  data pull toko.api.pesanan.idPesanan;
```
