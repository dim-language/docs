On Monday morning Dido picks up a ticket to document checkout. The product team has written one sentence. “A customer can place an order through the shop.” The Web and API teams will bring their designs tomorrow. Today Dido needs a map they can mark up together.

## Set up a project folder

Keep Dido’s map in a file called `toko.dim`. With Node.js 24 and Bun installed, run these commands in a terminal.

```sh
mkdir dim-checkout
cd dim-checkout
bun add https://github.com/dim-language/dim-sdk/releases/download/v0.2.0/dim-sdk-0.2.0.tgz
```

Save this as `check.mjs` in that folder. It reads the file you give it, runs the compiler and prints the element and relation counts. The example uses Indonesian names: `toko` means shop and `pesanan` means order. Keep them as written so the paths match.

```js contoh-tutorial="check.mjs"
```

## A person and a system

Create `toko.dim` with this model.

```dim contoh-tutorial="sistem.dim"
```

Each element has a kind (`person` or `system`), an ID used in code, and a name displayed on the map. The arrow `pembeli -> toko` shows that the customer starts the interaction. A declaration without a block ends with `;`.

```bash
node check.mjs toko.dim
```

```text contoh-tutorial="sistem"
```

Two elements and a relation show who uses the shop.
