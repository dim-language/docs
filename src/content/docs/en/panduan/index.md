title: Usage guides
description: Choose a guide for the change you want to make.
---

Choose the task in front of you. If you don’t have a `.dim` file yet, start with [your first model](/en/mulai/).

- [Map an existing system](/en/menulis/memodelkan/) — Start with one user, one action and the service that responds.
- [Separate the caller from data direction](/en/konsep/aliran-data/) — Record the request and response on one arrow.
- [Document an HTTP endpoint](/en/konsep/endpoint/) — Derive the method, path and response type from the route contract.
- [Trace a flow](/en/konsep/alur/) — Follow checkout from the click to the database write.
- [Split a model across files](/en/konsep/komposisi/) — Separate two teams’ systems and compile them from one entry point.
- [Read arrows at different zoom levels](/en/konsep/peta-zoom/) — Find the function that writes to the database.
- [Describe a function contract](/en/konsep/level-kode/) — Record parameters, return values and error conditions.
- [Choose elements and attributes](/en/menulis/elemen/) — Identify the system boundary and its containers.
- [Connect two elements](/en/menulis/relasi/) — Choose source and target paths and name their interaction.
