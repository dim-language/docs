title: Embed a map on an Astro page
description: Display your checkout model with the SDK map component.

import ShopMap from '../../../../examples/model-pertama/ShopMap.astro';
import source from '../../../../examples/model-pertama/kode.dim?raw';

In an Astro project, [install the SDK](/en/referensi/cli/#install). Copy the final `toko.dim` from the [tutorial](/en/mulai/) to `src/models/toko.dim`. Save the following component in `src/components/`.

```astro title="src/components/ShopMap.astro" contoh-tutorial="ShopMap.astro"
```

Create a page that reads the model file as text. The component compiles it when the page renders.

```astro title="src/pages/checkout.astro"
---
import ShopMap from '../components/ShopMap.astro';
import source from '../models/toko.dim?raw';
---
<ShopMap source={source} language="en" />
```

Start the Astro dev server and open `/checkout/`. Zoom until Web and API appear, then select the POST relation to inspect its request and response. Try it in the same component below.

<ShopMap source={source} language="en" />
