import ShopMap from '../../../examples/model-pertama/ShopMap.astro';
import source from '../../../examples/model-pertama/kode.dim?raw';
import config from '../../../examples/model-pertama/dim.config?raw';

In an Astro project, [install the SDK](/referensi/cli/#install). Copy the final `shop.dim` and its `dim.config` from the [tutorial](/mulai/) to `src/models/`. Save the following component in `src/components/`.

```astro title="src/components/ShopMap.astro" contoh-tutorial="ShopMap.astro"
```

Create a page that reads the model and its config as text. The component compiles it when the page renders.

```astro title="src/pages/checkout.astro"
---
import ShopMap from '../components/ShopMap.astro';
import source from '../models/shop.dim?raw';
import config from '../models/dim.config?raw';
---
<ShopMap source={source} config={config} language="en" />
```

Start the Astro dev server and open `/checkout/`. Zoom until Web and API appear, then select the POST relation to inspect its request and response. Try it in the same component below.

<ShopMap source={source} config={config} language="en" />
