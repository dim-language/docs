## “Baliknya satu order, kan?”

</header>
<img class="dim-scene" src="/brian/order-id.webp" width="640" height="374" alt="" loading="lazy" />
<div class="dim-example-body">

Kali ini Brian nanya dulu. Arsiteknya geleng. “ID-nya aja.” Mereka buka model dan catat kesepakatannya di panah **Web App → API**. Sekarang Brian bisa kasih agennya file yang bilang persis apa yang dikirim (`CheckoutRequest`) dan apa yang balik (`OrderId`).

```dim title="shop.dim"
checkout_post: web.checkout.button -> api.checkout.route "POST /checkout" {
  op call;
  tech "HTTPS/JSON";
  data push "CheckoutRequest";
  data pull "OrderId";
}
```

- data "CheckoutRequest";
