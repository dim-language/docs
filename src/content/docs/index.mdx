## Ikuti checkout dari toko sampai kode

Di model toko online ini, method `OrderRepository.save()` menyimpan pesanan ke Postgres. dim memakai relasi itu untuk menampilkan **API → Postgres** saat kamu melihat isi toko. Saat toko tertutup, relasi itu berada di dalam kotak **Online Shop**.

[Cara dim menghitung panah saat zoom](/konsep/peta-zoom/)

</div>
<div>

```dim title="shop.dim"
insert_order: api.orders.repo.save -> db "INSERT orders" {
  op write;
  data "Order";
}
```

</div>

## Catat data yang dikirim dan diterima

Tombol checkout memulai panggilan ke API. Dengan `data push`, Web App mengirim `CheckoutRequest`. Dengan `data pull`, Web App menerima `OrderId` dari API. Keduanya tercatat pada panah **Web App → API**.

[Cara menulis interaksi dan aliran data](/konsep/aliran-data/)

</div>
<div>

```dim title="shop.dim"
checkout_post: web.checkout.button -> api.checkout.route "POST /checkout" {
  op call;
  tech "HTTPS/JSON";
  data push "CheckoutRequest";
  data pull "OrderId";
}
```

</div>

## Cek model di terminal dan CI

Pakai `compileProject` untuk memeriksa model beserta file yang diimpor. Misalnya, jika kamu menghapus `push` dari `data push "CheckoutRequest"`, compiler melaporkan `E035` pada baris yang perlu diperbaiki. Kamu juga bisa menjalankan pemeriksaan yang sama di CI.

[API SDK dan format diagnostik](/referensi/cli/)

</div>
<div>

```ts
const { diagnostics } = compileProject("main.dim", files);
```
