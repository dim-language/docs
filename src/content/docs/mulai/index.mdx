On Monday morning Dido picks up a ticket to document checkout. The product team has written one sentence. “A customer can place an order through the shop.” The Web and API teams will bring their designs tomorrow. Today Dido needs a map they can mark up together.

## Set up a project folder

Keep Dido’s map in a file called `shop.dim`. With Node.js 24 and Bun installed, run these commands in a terminal.

```sh
mkdir dim-checkout
cd dim-checkout
bun add https://github.com/dim-language/dim-sdk/releases/download/v0.3.1/dim-sdk-0.3.1.tgz
```

Save this as `check.mjs` in that folder. It reads the file you give it and the `dim.config` next to it, runs the compiler and prints the element and relation counts.

```js contoh-tutorial="check.mjs"
```

Also save `dim.config` in the same folder. Here Dido declares the technologies the teams will use, once for the whole project.

```dim contoh-tutorial="dim.config"
```

## A person and a system

Create `shop.dim` with this model.

```dim contoh-tutorial="sistem.dim"
```

Every file starts with `dim "0.6";`. Each element has a kind (`person` or `system`), a camelCase ID used in paths, and a name displayed on the map. The `shopping` relation has an id and `op use`, and its arrow shows that the customer starts the interaction. Every statement without a block ends with `;`.

```bash
node check.mjs shop.dim
```

```text contoh-tutorial="sistem"
```

Two elements and a relation show who uses the shop.
