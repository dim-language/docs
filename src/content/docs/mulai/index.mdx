Senin pagi, Dido dapat tiket untuk mendokumentasikan checkout toko online. Di tiket cuma ada satu kalimat dari tim produk. “Pembeli bisa pesan lewat toko.” Besok tim Web dan API akan membawa rancangan mereka. Hari ini Dido perlu menyiapkan peta yang bisa mereka koreksi bersama.

## Siapkan folder kerja

Simpan peta Dido di satu file `toko.dim`. Siapkan Node.js 24 dan Bun, lalu jalankan perintah berikut di terminal.

```sh
mkdir dim-checkout
cd dim-checkout
bun add https://github.com/dim-language/dim-sdk/releases/download/v0.2.0/dim-sdk-0.2.0.tgz
```

Simpan kode berikut sebagai `check.mjs` di folder itu. Skrip ini membaca file yang kamu berikan, menjalankan compiler, lalu mencetak jumlah elemen dan relasinya.

```js contoh-tutorial="check.mjs"
```

## Orang dan sistem

Buat file `toko.dim` dan isi dengan model berikut.

```dim contoh-tutorial="sistem.dim"
```

Setiap elemen punya jenis (`person` atau `system`), ID yang dipakai dalam kode, dan nama yang tampil di peta. Panah `pembeli -> toko` menunjukkan bahwa pembeli yang memulai interaksi. Deklarasi tanpa blok diakhiri dengan `;`.

```bash
node check.mjs toko.dim
```

```text contoh-tutorial="sistem"
```

Dua elemen dan satu relasi sudah cukup untuk menggambarkan siapa yang memakai toko online.
