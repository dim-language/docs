Saat mencoba prototipe di ponsel, tim produk memutuskan untuk menampilkan nomor pesanan saja. Tim API pun memangkas respons checkout. Dido menemukan satu baris di model yang sekarang sudah basi.

<DidoNote scene="order-id">Kalau yang balik cuma ID, bagian mana dari panah POST yang mesti gue ubah?</DidoNote>

Di `toko.dim`, edit relasi POST saja. Web masih mengirim pesanan lengkap dan API masih menyimpannya.

```diff
- toko.web -> toko.api "POST /pesanan" { op call; data push "Pesanan"; data pull "Pesanan" }
+ toko.web -> toko.api "POST /pesanan" { op call; data push "Pesanan"; data pull "IdPesanan" }
```

```sh
node check.mjs toko.dim
```

## Periksa arah saat review

Jumlah panah tetap sama. Untuk melihat apa yang diperiksa compiler, coba hapus kata `push` dari request dan jalankan lagi perintah tadi.

```text contoh-tutorial="tanpaArah"
```

Untuk `op call`, setiap tipe data perlu arah. Kembalikan `push`, jalankan cek sampai muncul `ok`, lalu cocokkan `data pull "IdPesanan"` dengan respons yang disepakati tim API. Tipe yang dijanjikan ke Web tetap perlu diperiksa saat review.
