After trying the prototype on a phone, the product team decides to show just the order number. The API team trims the checkout response. Dido spots the line in his model that has just gone stale.

<DidoNote scene="order-id">If all we get back is the ID, which part of the POST arrow do I change?</DidoNote>

In `shop.dim`, add a type for the order number to the Orders component, then change only the `pull` part of the POST relation. Web still sends a full order and the API still persists it.

```diff
+      alias orderId "OrderId" {
+        description "The order number shown on the confirmation screen.";
+        type uuid;
+      }
```

```diff
-  data pull shop.api.orders.order;
+  data pull shop.api.orders.orderId;
```

```sh
node check.mjs shop.dim
```
